把 InsightHub 数据接入你的 AI Agent

通过 MCP（Model Context Protocol），在 Claude Desktop、Cursor、Cline 等工具中直接调用行业趋势、竞品分析、企业查询等数据能力，无需切换网页。

选择你的客户端
不同客户端配置方式略有差异，选择后下方代码会自动适配
Claude Desktop
Cursor
Cline
Windsurf
配置你的 API Key
选择用于 MCP 调用的 Key，将自动生成对应配置文件
接入步骤
可用 MCP 工具（创业商业情报包）
订阅其他数据包后会自动解锁对应工具
insighthub_industry_trends
查询指定行业的趋势数据与增速
insighthub_project_evaluate
输入项目方向，返回可行性评分
insighthub_competitor_list
生成指定领域的竞品列表
insighthub_generate_report
调用 AI 生成完整商业分析报告
测试连接
配置完成后重启客户端，尝试发送以下消息验证
我
帮我用 InsightHub 查一下 AI 客服 SaaS 这个行业的趋势
AI
已调用 insighthub_industry_trends。该行业近 3 年年均增速约 34%，市场处于高速扩张阶段……
若 AI 能正常调用工具并返回数据，说明 MCP 接入成功
