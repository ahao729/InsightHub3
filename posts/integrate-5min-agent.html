如何在 5 分钟内将 InsightHub 接入你的 AI Agent

InsightHub 全面支持 MCP（Model Context Protocol）协议，这意味着你可以将 InsightHub 的数据能力直接接入任何支持 MCP 的 AI 工具或 Agent 框架，让 AI 模型实时查询和分析商业数据。本文将在 5 分钟内带你完成从注册到数据查询的完整配置流程。

前提条件

  • 一个 InsightHub 账号（免费注册）
  • 支持 MCP 客户端的 AI 工具，如 Claude Desktop、VS Code 中的 AI 插件，或自定义的 MCP Agent 框架
  • 基本的 JSON 编辑能力与终端操作经验

第一步：获取 API Key

登录 InsightHub 控制台，在左侧导航栏中找到"API 密钥"页面。点击"创建新密钥"，为你的密钥命名（例如"My AI Agent"），选择所需的数据权限范围（建议初始使用"只读"权限），然后点击确认。系统会生成一串以 ih_ 开头的 API Key。

注意：请将密钥保存在安全位置，离开此页面后将无法再次查看完整密钥内容。如果密钥泄露，可以在控制台中随时撤销并重新生成。

第二步：配置 MCP Server

在你的 AI 工具的 MCP 配置文件中添加 InsightHub 数据源。以下是一个标准的 MCP 配置示例：

{
  "mcpServers": {
    "insighthub": {
      "command": "npx",
      "args": [
        "-y",
        "@insighthub/mcp-server"
      ],
      "env": {
        "INSIGHTHUB_API_KEY": "ih_your_api_key_here",
        "INSIGHTHUB_BASE_URL": "https://api.insighthub.io"
      }
    }
  }
}

将配置中的 INSIGHTHUB_API_KEY 替换为你在第一步中获取的实际密钥。如果你的 AI 工具运行在企业网络环境中，还可以通过 INSIGHTHUB_BASE_URL 指定自定义的 API 网关地址或私有化部署端点。

第三步：在 AI 工具中使用

完成配置后，保存配置文件并重启你的 AI 工具。现在，你可以直接在对话中通过自然语言查询 InsightHub 的数据了。例如：

  • "查询 2026 年第二季度电商行业的投融资数据"
  • "对比过去三个月新能源汽车品牌的社交媒体声量趋势"
  • "帮我分析最近一周专利申请量增长最快的技术领域"
  • "列出 2026 年融资额最高的 10 家 AI 应用层创业公司"

AI 工具会自动调用 InsightHub 的 MCP 工具，将数据查询结果纳入上下文进行智能回答。无需手动切换平台或编写 API 调用代码，所有数据查询在对话流中自然完成。

整个配置过程通常不超过 5 分钟。如果你希望了解更多高级配置选项，包括自定义工具函数、数据过滤规则和结果缓存策略，请查阅我们的完整 MCP 集成文档与最佳实践指南。
