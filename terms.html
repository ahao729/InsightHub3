欢迎使用 InsightHub Data 平台。以下条款（"本条款"）构成您（"用户"）与 InsightHub Data（"我们"）之间关于访问和使用本平台服务的完整协议。使用即表示您同意受本条款约束。

1. 服务概述

InsightHub Data 是一个数据 API 聚合与分发平台。我们汇集来自多个来源的商业情报、金融数据、AI 分析等数据，以标准化 API 数据包的形式向用户提供。具体可用数据包及其规格以 市场页面 公示为准。

  • 平台提供 RESTful API 接口，用户通过 API Key 鉴权调用；
  • 部分服务支持 MCP (Model Context Protocol) 协议接入；
  • 平台提供 Webhook 推送和报告生成等附加功能。

2. 账户与注册

2.1 您必须提供真实、准确、完整的注册信息，并保持信息的及时更新。

2.2 您对账户下的所有活动负责。请妥善保管登录凭证和 API Key，不得分享给未经授权的第三方。

2.3 如发现账户异常或安全漏洞，您须立即通知我们。对于因账户信息泄露导致的损失，我们概不承担责任。

2.4 每个个人或实体仅限注册一个免费试用账户。滥用试用机制（包括但不限于注册多个账户以获取额外免费额度）将导致所有关联账户被终止。

3. 订阅与付费

3.1 数据包提供月度订阅制，费用以人民币 (CNY) 计价，含适用税费。

3.2 付费订阅自动续费，除非您在续费日之前取消。取消后，当前计费周期内的服务继续有效至周期结束。

3.3 我们可能在提前 30 天通知的情况下调整订阅价格。价格调整不影响已付款的当前周期。

3.4 所有费用均不予退款，除非法律另有规定或我们书面同意。7 天内取消的新订阅可申请全额退款。

3.5 逾期未支付可能导致服务暂停，暂停 30 天后仍未支付的，我们有权终止账户。

4. 数据包许可

4.1 订阅数据包后，您获得一项非独占、不可转让、不可再许可的全球范围内有限许可，可在订阅期内通过 API 调用获取和使用数据。

4.2 您可以将数据结果用于内部商业分析、产品开发和 AI 模型训练，前提是：

  • 不得将原始数据或实质性衍生数据以原始形式再分发、转售或提供给第三方；
  • 不得用于构建直接与 InsightHub Data 竞争的数据聚合产品；
  • 如数据包含第三方来源信息，须遵守该来源的附加使用限制。

4.3 不同数据包的 API 调用频率限制（Rate Limit）和并发限制在 API 文档 中列明，超出限制的调用将被拒绝。

5. 使用限制

5.1 您同意不会将平台用于以下目的：

  • 违反法律法规或侵犯第三方权利；
  • 传播恶意软件、进行网络攻击或干扰平台正常运行；
  • 绕过或破坏平台的访问控制、计费机制或安全措施；
  • 对平台进行压力测试、爬取或反向工程（明确授权的安全测试除外）。

5.2 我们保留在不另行通知的情况下暂停违反使用限制的账户的权利。

6. 服务等级

6.1 我们承诺付费订阅用户月度可用性不低于 99.5%（"SLA"）。可用性以每月 API 成功请求数占总请求数的百分比计算。

6.2 若可用性低于 99.5%，您可申请月度费用的 5% 作为服务额度补偿；低于 99.0% 时补偿提升至 10%。

6.3 以下情形不计入 SLA：计划内维护（提前 48 小时通知）、第三方数据源故障、不可抗力、以及用户自身原因导致的故障。

6.4 实时系统状态请参阅 系统状态页面。

7.1 InsightHub Data 平台（包括但不限于网站、API、品牌标识、UI 设计）的所有权利归我们所有。

7.2 各数据包中涉及的第三方数据来源的知识产权归相应来源方所有。我们依法获得分发授权。

7.3 您使用平台生成的报告和分析成果，其知识产权归您所有，但您授予我们为提供服务所需的必要使用权限。

8. 免责声明

8.1 平台按"现状"提供，我们不对数据的准确性、完整性或时效性做任何明示或暗示的保证。

8.2 在法律允许的最大范围内，我们不对因使用或无法使用平台导致的间接、附带、特殊或后果性损害承担责任。

8.3 我们的累计赔偿责任不超过您在索赔前 12 个月内向我们支付的费用总额。

9. 终止

9.1 任何一方可随时终止本条款。您的终止需停止使用平台并注销账户。

9.2 如果您严重违反本条款，我们可在通知后立即终止您的账户。

9.3 终止后，您访问平台和 API 的权利立即终止。我们将在 30 天内根据隐私政策处理您的数据。
